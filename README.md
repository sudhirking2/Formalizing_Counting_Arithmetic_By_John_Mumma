# Formalizing_Counting_Arithmetic_By_John_Mumma
This project formalizes an alternative two-sorted first-order theory of arithmetic, called Counting Arithmetic, by John Mumma in Lean4. 
A huge thanks to both Erich Reck and John Mumma for their encouragement throughout this project!

Note the alternative axioms replace I6 and I7 by injectivtiy of pairing, deletes I8, replaces I10 by just the statement natural indicies are all greater than or equal to 1, and deletes S3. 

The goal is to mdoify the o.g. axioms so that we can construct a model in which I can be thought of as the positive integers, S the collection of all finite subsets of positive integers, and the pairing operation is taken as Cantor's pairing function.
